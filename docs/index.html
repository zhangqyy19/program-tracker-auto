"Check now" queries the sources that allow browser requests (Greenhouse job boards) directly from your browser. Company pages such as Citadel, D. E. Shaw and Two Sigma block that, so they are checked by a GitHub Actions job every 6 hours. To trigger that job from this button, add a GitHub fine-grained token for this repository with Actions: read and write permission. The token stays in this browser's local storage only.

Sources are listed per program in programs.json. Status heuristics can be wrong; always confirm on the official page before relying on a deadline.
